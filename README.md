# V Vijay — Web Developer Portfolio

A responsive, single-page portfolio showcasing Vijay's web development projects, skills, education, and contact details.

## About

Based in Coimbatore, India. Vijay holds a Bachelor of Commerce in Corporate Secretaryship and Computer Applications from Bharathiyar University (2022–2025), and is building full-stack skills through MERN training.

## Featured projects

- **SmartFitPro** — Responsive smartwatch landing page built with HTML, CSS, and JavaScript.
- **QuickFix Marketplace** — Service marketplace with customer, provider, and admin workflows, job requests, chat, and real-time notifications. Built with React, Node.js, Express, MongoDB, and Socket.IO.
- **Aadvik Boutique** — Responsive boutique storefront with dynamic product rendering and collection search, built with HTML, CSS, and JavaScript.
- **ShopHub E-Commerce** — Online store with product search, shopping cart, wishlist, reviews, and order management, built with HTML, CSS, JavaScript, Node.js, Express, and MongoDB.

Each project card links to its source repository. Browse [all GitHub repositories](https://github.com/vijay-890?tab=repositories).

## Portfolio features

- Responsive navigation and mobile menu
- Animated Three.js hero background
- Scroll and project-card animations
- Skills and project sections
- Contact form that opens a prefilled email draft for the visitor to review and send

## Technologies

HTML, CSS, and JavaScript, with Three.js and GSAP loaded from public CDNs. The portfolio itself has no build step or package installation.

## Run locally

Open `index.html` in a browser. An internet connection is needed to load the external fonts and animation libraries.

## Deployment

This repository is published with GitHub Pages.
